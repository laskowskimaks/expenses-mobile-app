# Expenses Mobile App

Aplikacja mobilna na system Android do monitorowania wydatków.


## Wymagania

- Node.js (wersja 16 lub nowsza)
- npm lub yarn
- Expo CLI
- Emulator Android/iOS lub urządzenie fizyczne z aplikacją Expo Go

## Instalacja i uruchomienie

1. Zainstaluj zależności:
   ```bash
   npm install
   ```

2. Uruchom aplikację:
   ```bash
   npx expo start
   ```

3. Wybierz platformę:
   - Naciśnij `a` dla emulatora Android
   - Naciśnij `i` dla symulatora iOS
   - Zeskanuj kod QR aplikacją Expo Go na urządzeniu fizycznym


## Technologie

- [Expo](https://expo.dev) - Framework React Native
- [React Native Paper](https://reactnativepaper.com/) - Komponenty UI Material Design
- [Drizzle ORM](https://orm.drizzle.team/) - ORM dla SQLite
- [Firebase](https://firebase.google.com/) - Autoryzacja i storage
- [Expo Router](https://docs.expo.dev/router/introduction/) - Nawigacja oparta na plikach
